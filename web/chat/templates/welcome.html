This website opens the same encrypted conversations as the Stratus terminal.

There is no username or password here on purpose. Your identity is your Linux device, so Chat is opened from the terminal:

  1. Run ./stratus.sh terminal and join your server.
  2. Open Encrypted Chat and choose Enable Browser Access once, to pick a browser passphrase.
  3. Open Hosted Applications, select stratus-chat and press Open in Browser.

The link that opens is valid once and for a minute, so it is safe if someone sees it over your shoulder.
